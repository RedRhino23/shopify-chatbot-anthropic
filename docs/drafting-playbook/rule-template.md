### R-000 Short name
- **Rule:** one sentence, as an instruction.
- **Why:** what goes wrong if it is skipped.
- **Check:** how we know it passed. Say auto, visual or manual, and name the script or the thing Ross looks at.
- **Fail example:** a real case, job number only, no client names.
- **Source:** job number and date it came from.
- **Status:** draft / manual / auto / retired
